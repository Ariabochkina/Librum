## О проекте

**Librum** - консольное приложение для ведения личной коллекции книг: добавление, правка, поиск по таблице, визуальный календарь изданий и подбор «что почитать дальше» на основе ваших оценок.

Данные живут в файлах JSON или CSV. По ISBN приложение умеет подтягивать метаданные и обложки из [Open Library](https://openlibrary.org) - без ручного заполнения всех полей.

| | |
| --- | --- |
| **Тип** | консольное приложение (CLI) |
| **Стек** | C#, .NET 8, Spectre.Console |
| **Данные** | JSON / CSV + Open Library API |
| **Год** | 2024-2025 |

## Возможности

### Библиотека
- просмотр всех книг
- добавление вручную (название, автор, жанр, год, ISBN)
- редактирование отдельных полей
- удаление книги

### Интерактивная таблица
- сортировка по любому полю (возрастание / убывание)
- фильтрация с мультивыбором значений
- стек команд: можно накладывать несколько сортировок и фильтров, удалять отдельные шаги
- при выходе выбранное представление применяется к библиотеке

### Календарь изданий
- выбор столетия (XV-XXI)
- сетка 10×10 по годам
- яркость ячейки отражает, сколько книг этого года есть в коллекции (от тёмно-серого до почти белого)

### Рекомендации
- до 5 непрочитанных / неоценённых книг
- рейтинг = средняя оценка автора + средняя оценка жанра по уже оценённым книгам
- сортировка по убыванию «подходящести»

### Файлы
- импорт и экспорт в **JSON** и **CSV**
- при выходе - автосохранение в исходный файл

### Open Library
- сверка и исправление полей всех книг по ISBN
- добавление книги только по ISBN
- загрузка обложки: сохранение PNG и вывод картинки прямо в терминал

## Модель данных

Каждая книга описывается полями:

| Поле | Смысл | Ограничения |
| --- | --- | --- |
| `Name` | название | по умолчанию «Неизвестно» |
| `Author` | автор | по умолчанию «Неизвестно» |
| `Genre` | жанр | по умолчанию «Другое» |
| `Date` | год издания | 1456 … текущий год |
| `ISBN` | ISBN-10 или ISBN-13 | проверка контрольной суммы |
| `Grade` | оценка | -1 (не оценено) … 10 |

Пример JSON:

```json
{
  "Books": [
    {
      "Name": "1984",
      "Author": "Джордж Оруэлл",
      "Genre": "Фантастика",
      "Date": 1949,
      "ISBN": "9785170801152",
      "Grade": 10
    },
    {
      "Name": "Romeo and Juliet",
      "Author": "William Shakespeare",
      "Genre": "Bibliography",
      "Date": 2015,
      "ISBN": "9781514697856",
      "Grade": -1
    }
  ]
}
```

Пропущенные поля при загрузке заполняются значениями по умолчанию.

## Быстрый старт

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download).

### 1. Клонировать и запустить

```bash
git clone https://github.com/Ariabochkina/Librum.git
cd Librum
dotnet run --project Librum
```

### 2. Что вводить при старте

Сразу после запуска приложение спросит:

```text
Введите путь
```

Нужно указать **путь к существующему JSON-файлу** с библиотекой (формат - в разделе [Модель данных](#модель-данных)).

Пример: сохраните файл `books.json` рядом с решением:

```json
{
  "Books": [
    {
      "Name": "1984",
      "Author": "Джордж Оруэлл",
      "Genre": "Фантастика",
      "Date": 1949,
      "ISBN": "9785170801152",
      "Grade": 10
    }
  ]
}
```

и введите путь к нему, например:

```text
./books.json
```

или абсолютный путь:

```text
/home/you/Librum/books.json
```

Если путь неверный или файл битый - будет сообщение об ошибке, после любой клавиши можно ввести путь снова.

### 3. Дальше - меню

После успешной загрузки открывается интерактивное меню (стрелки + Enter):

- просмотр / добавление / редактирование / удаление книг
- таблица, календарь, рекомендации
- импорт и экспорт JSON/CSV
- функции Open Library (по ISBN и обложки)
- **Выход** - сохраняет изменения обратно в тот же файл, из которого загрузили библиотеку

Сборка solution целиком:

```bash
dotnet build Librum.sln
```

> Для функций Open Library нужен интернет. Обложки сохраняются в корень репозитория как `{ISBN}.png`.

## Как устроены «умные» фичи

### Рекомендации
1. По оценённым книгам считаются средние баллы **по автору** и **по жанру**.
2. Для каждой книги с `Grade == -1` считается сумма этих двух средних.
3. Топ-5 с наибольшей суммой показываются как рекомендации.

### Календарь
Для выбранного столетия строится сетка лет; цвет ячейки зависит от числа книг с этим годом издания - визуальный «heatmap» коллекции.

### ISBN
При вводе проверяется длина (10 или 13) и контрольная сумма. Через Open Library по ISBN подтягиваются title, author, subjects, publish date и cover.
