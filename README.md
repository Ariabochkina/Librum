# Менеджер библиотеки
## Выбранная ветка:
B side
## Формат входных данных:
JSON вида:
```
{
  "books": [
    {
      "Name": "1984",
      "Author": "Джордж Оруэлл",
      "Genre": "Фантастика",
      "Date": 1949,
      "ISBN": "9785170801152",
      "Grade": -1
    }
  ]
}
```
Дата: от 1456 до настоящего года
Оценка: от -1 до 10
Жанры: 
• Фантастика
• Детектив
• Роман
• История
• Научная литература
ISBN: корректный
## Общее описание меню:
• Просмотр всех книг
• Добавление новой книги: заполнение всех полей
• Редактирование информации о книге: выбор книги для изменения, выбор поля для изменения, заполнение новым значением
• Удаление книги: выбор книги для удаления
• Интерактивная таблица: представление всех книг таблицей, которую можно:
    • Сортировать: выбор поля для сортировки, выбор направления сортировки
    • Фильрация: выбор поля для фильрации, выбор значений (которых следует оставить в таблице)
    • Удаление: выбор и удаление одной из существующих команд (сортировка/фильтрация со своими номерами)
    • Выход: сохранение получившегося представления таблицы (с сохранением сортировок/фильтраций)
• Календар: выбор столетия (от 15 до 21), таблица всех годов одного столетия, демонстрирующая яркостью цвета 
(от темно-серого - 0 книг, до белого - больше 15) количество книг, хранящихся в библиотеке за год
• Рекоммендации: список рекоммендованных книг (максимум 5) в порядке убывания (1 книга - самая подходящая читателю)
по выставленным оценкам. Рекоммендации проводятся на основе суммарного рейтинга за рейтинг по автору и рейтинг по жанру
• Экспорт: запрашивает путь до файла (если необходимо создает новый), выбор формата для экспорта (CSV/JSON)
• Импорт: запрашивает путь до файла (если необходимо создает новый), выбор формата для импорта (CSV/JSON)
• Выход: сохраняет со всеми изменениями книги в файл, из которого получена информация о книгах в формате JSON (если необходимо создает новый)
## Описание структуры проекта:
В ConsoleApp21 расположены классы, реализующие функции приложения
В Files расположены классы, работающие с файлами
В Library расположены классы, хранящие информацию о книгах
