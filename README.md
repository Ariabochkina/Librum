# Менеджер библиотеки
## Выбранная ветка:
B side
## Формат входных данных:
JSON вида:
```
{
  "Books": [
    {
      "Name": "1984",
      "Author": "Джордж Оруэлл",
      "Genre": "Фантастика",
      "Date": 1949,
      "ISBN": "9785170801152",
      "Grade": 10
    },
{
      "Name": "Romeo and Juliet",
      "Author": "William Shakespeare",
      "Genre": "Bibliography",
      "Date": 2015,
      "ISBN": "9781514697856",
      "Grade": -1
    }
  ]
}
```
Дата: от 1456 до настоящего года

Оценка: от -1 (не прочитано/не оценено) до 10 (высшая оценка)

ISBN: корректный, без разделителей между цифрами

## Общее описание меню:
### Просмотр всех книг
### Добавление новой книги: 
• Заполнение всех полей
### Редактирование информации о книге: 
• Выбор книги для изменения

• Выбор поля для изменения

• Заполнение новым значением
### Удаление книги: 
• Выбор книги для удаления
### Интерактивная таблица: 
• Представление всех книг таблицей, которую можно:

  - Сортировать: выбор поля для сортировки, выбор направления сортировки
    
  - Фильрация: выбор поля для фильрации, выбор значений (которых следует оставить в таблице)
    
  - Удаление: выбор и удаление одной из существующих команд (сортировка/фильтрация со своими номерами)
    
  - Выход: сохранение получившегося представления таблицы (с сохранением сортировок/фильтраций)
    
### Календарь: 
• Выбор столетия (от 15 до 21)

• Таблица всех годов одного столетия, демонстрирующая яркостью цвета 

(от темно-серого - 0 книг, до белого - больше 15) количество книг, хранящихся в библиотеке за год
### Рекоммендации: 
• Список рекоммендованных книг (максимум 5) в порядке убывания (1 книга - самая подходящая читателю)
по выставленным оценкам. 

Рекоммендации проводятся на основе суммарного рейтинга за рейтинг по автору и рейтинг по жанру
### Экспорт: 
• Запрашивает путь до файла (если необходимо создает новый)

• Выбор формата для экспорта (CSV/JSON)
### Импорт: 
• Запрашивает путь до файла (если необходимо создает новый)

• Выбор формата для импорта (CSV/JSON)
### Исправление всех данных на основе openlibrary:
• Сверяет все книги по ISBN с openlibrary

• В случае существования такого ISBN в openlibrary и расхождений в каких-либо полях - исправляет некорректные значения
### Добавление книги по ISBN:
• Заправшивает ISBN

• В случае существования такого ISBN в openlibrary - добавляет в библиотеку
### Загрузка обложки по вашей книге:
• Выбор книги для обложки

• В случае существования такого ISBN в openlibrary- вывод обложки в консоль, запись в файл и вывод пути до этого файла от корня проекта
### Выход: 
• Сохраняет со всеми изменениями книги в файл, из которого получена информация о книгах в формате JSON (если необходимо создает новый)
## Описание структуры проекта:

В ConsoleApp21 расположены классы, реализующие функции приложения

В Files расположены классы, работающие с файлами

В Library расположены классы, хранящие информацию о книгах
